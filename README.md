# GeoLab - Mini App di Geometria

GeoLab è un'app didattica open source per scuole primarie e secondarie.

## Contenuti
- Interattiva e visiva
- Modalità compiti e quiz
- Figure geometriche: rettangolo, quadrato, triangolo, parallelogramma
- Piano cartesiano e coordinate

## Manuali
- Docente: strategie didattiche, livelli scolastici, esercizi
- Studente/Famiglia: uso semplificato, compiti, esercizi guidati
